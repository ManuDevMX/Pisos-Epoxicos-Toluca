# Pisos Epóxicos Toluca 🛠️

Sitio web profesional, moderno y responsivo desarrollado para la empresa **Pisos Epóxicos Toluca**, especializada en la instalación de recubrimientos industriales, comerciales y residenciales.

🌐 **Demo en vivo:** [https://manudevmx.github.io/pisos-epoxicos-toluca/](https://manudevmx.github.io/pisos-epoxicos-toluca/)

---

## 🚀 Características Principales

* 📱 **Diseño 100% Responsivo:** Adaptabilidad total a dispositivos móviles, tablets y computadoras de escritorio.
* 🖼️ **Galería Interactiva con Visor:** Tarjetas de proyectos estructuradas con contenedor oculto y visor dinámico en JavaScript para explorar los procesos paso a paso.
* 💬 **Cotización Directa por WhatsApp:** Formulario interactivo que procesa metros cuadrados, tipo de servicio y mensaje para iniciar un chat con los datos redactados.
* ⚡ **Animaciones Fluidas:** Uso de `IntersectionObserver` para un despliegue suave de secciones al hacer scroll.
* 🎨 **UI/UX Industrial:** Encabezado tipo Hero con superposición oscura, navegación menú "sticky" y paleta de colores corporativos.
* 📜 **Banner de Cookies y Páginas Legales:** Cumplimiento con Términos, Condiciones y Aviso de Privacidad respaldado en `localStorage`.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructuración semántica de alto rendimiento.
* **CSS3:** Maquetación moderna con CSS Grid, Flexbox y media queries optimizadas.
* **JavaScript (ES6+):** Manipulación del DOM, navegación táctil (swipe) para móviles y lógica de formularios.
* **GitHub Pages:** Hosting y despliegue continuo.
